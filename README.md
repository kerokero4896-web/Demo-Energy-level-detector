# Demo · 에너지 레벨 감지기

에너지를 실제보다 높게 어림잡고 무리하다 뻗는 패턴을 막으려고 만든 1분 점검 앱의 **시연판**입니다.
**느낌으로 잰 에너지**와 **몸·마음 신호로 잰 에너지**를 한 눈금에 나란히 보여 주고, 둘 중 낮은 쪽에 맞춰 오늘 계획 크기를 정해 줍니다.

- 시연 주소: VERCEL_URL
- 휴대폰에서 열면 실제 쓰는 화면과 같은 크기로 볼 수 있어요.

## 시연판은 이렇게 달라요

- **예시 기록 12일치**가 들어 있어요. 지어낸 값이고, 실제 사람의 기록이 아니에요.
- 체크하거나 결과를 눌러 볼 수 있지만, 기록은 **그 창에만 잠깐** 남아요. 새로고침하면 처음 예시 기록으로 돌아가고, 어디로도 보내지 않아요.
- 실제 앱은 claude.ai 안에서 돌아가고, 기록은 앱 주인 계정에만 저장돼요. 이 저장소에는 시연판만 있어요.

## 쓰는 법

| 언제 | 무엇을 |
|---|---|
| 아침 | "오늘 체크 시작" → 느낌 점수 → 잠과 몸 → 생활 리듬 → 부하 → 몸·마음 경고등 → 브레이크 점검 → 결과 |
| 하던 일 중간 | "지금 멈춰야 할까?"에서 해당하는 것만 눌러 보기 (저장 안 함) |
| 다음 날 | "어제는 어땠어요?"에 한 번 누르기 (여유 · 딱 맞음 · 무리 · 뻗음). 체크하고 결과를 안 남긴 지난 며칠(3일까지)도 차례로 물어요 |

결과가 쌓이면 "기록"에서 내 느낌이 신호보다 평균 몇 점 높게 나오는지, 무리하거나 뻗은 날 아침에는 어땠는지 보여 줍니다.

## 점수 계산

10점에서 시작해서 고른 항목마다 더하거나 깎습니다. 0~10점이고 10점을 넘지 않으며, 느낌을 높게 잡지 않도록 0.5점 단위로 내림합니다 (예: 9.25 → 9).

| 항목 | 깎는 점수 |
|---|---|
| 어젯밤 잔 시간: 5시간 미만 / 5~6시간 / 6~7시간 / 7시간 이상 | −3 / −2 / −1 / 0 |
| 일어났을 때: 개운 / 보통 / 찌뿌둥 / 거의 못 잠 | 0 / −0.5 / −1 / −2 |
| 어제 몸을 얼마나 움직였나: 거의 안 움직임 (집에만, 1천 보 아래) / 가볍게·적당히 (걷기·가벼운 러닝) / 세게 (근력·주짓수·오래 달리기) | −1 / +0.5 / 0 |
| 생활 리듬 7개 중 지킨 개수: 6~7 / 4~5 / 2~3 / 0~1 (정한 시간 기상, 씻고 갈아입기, 끼니, 하루 메모, 명상/기도, 자기 전 정리, 폰 떼고 자기) | 0 / −0.5 / −1.5 / −2 |
| 지난 3일 중 무리한 날: 0 / 1 / 2 / 3일 | 0 / −0.5 / −1.5 / −2.5 |
| 오늘 지금까지 쓴 에너지 (낮 12시 이후나 그날 두 번째 체크부터): 거의 안 씀 / 조금 / 꽤 / 많이 | 0 / −0.5 / −1 / −2 |
| 새벽 1시 넘어서 잤다 | −0.5 |
| 어제 사람을 많이 만났다 · 어제 멀리 다녀왔다 · 어제 마음 쓰는 일이 있었다 (갈등·무거운 대화) | 각 −1 |
| 그저께 사람을 많이 만났거나 멀리 다녀왔다 (어제 체크에서 사람·외출을 골랐으면 미리 채움) | −0.5 |
| 감기·몸살 기운이나 아픈 데가 있다 | −1 |
| 몸 경고등 4개 · 마음 경고등 4개 | 하나마다 −0.5 |
| 브레이크 세 기준: 동기(불안·조급함이 연료) · 제어(멈추려 해도 안 멈춰짐) · 감각(일상이 무채색) | 하나마다 −0.75 |
| 느낌을 부풀리는 것: 들떠 있다 · 다 할 수 있을 것 같다 | 0 (과대평가 위험만 표시) |
| 느낌을 부풀리는 것: 끈기로 밀어붙이는 중 · 커피로 버티는 중 | 하나마다 −0.5 |

- 구간: 8~10 충분 · 6~7.5 보통 · 4~5.5 낮음 · 0~3.5 바닥
- 오늘 계획 크기는 느낌과 신호 중 **낮은 쪽**에 맞춥니다. 충분: 큰 일 3개까지 / 보통: 2개까지 / 낮음: 1개 + 작은 일 / 바닥: 꼭 해야 할 일 1개만
- 생활 리듬은 컨디션이 괜찮을 때는 하다가 흔들리면 먼저 빠지는 행동들이라, 하나하나보다 지킨 개수로 봅니다. 기록에 날마다 "리듬 5/7"을 보여 주고, 이틀 연속 줄거나 이틀 연속 절반 아래(7개면 3개 이하)면 오늘 판정에서 알려 줍니다.
- 오늘 이미 잡힌 큰 일(약속·외출·면접 등)은 점수에 넣지 않고 계획 크기에서 뺍니다. 예: 보통(큰 일 2개까지)인데 이미 2개가 잡혀 있으면 "새로 넣지 않기"
- 브레이크 세 기준 중 하나라도 켜지거나 신호가 3.5 이하면 "멈춤 → 회복 → 복귀"를 안내합니다.
- 어제 결과가 "뻗음"이면 오늘 판정에 "뻗은 다음 날은 또 뻗기 쉬워요. 오늘은 회복부터"와 회복 메뉴를 보여 줍니다.
- 하루는 새벽 5시에 바뀝니다. 새벽 2시에 한 체크는 전날 기록이 됩니다.
- 처음 기준은 대략적입니다. 기록이 쌓이면 실제로 뻗은 날에 맞춰 고쳐 갑니다.
  - 기준 6: "어제 움직임"에서 세게 −0.5 → 0, 거의 안 움직임 −0.5 → −1 (기록과 맞춰 보고 바꿈)
  - 기준 7: "그저께 사람·외출" −0.5 추가, "거의 안 움직임"에 걸음 수 기준(1천 보 아래), 뻗은 다음 날 안내 (기록과 맞춰 보고 더함)

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 전체. 원본 앱과 똑같은 파일이에요 (여기서 고치지 않아요) |
| `build.js` | 시연 화면 만들기: `index.html`에 겉틀과 시연용 손질(창 제목, 시연 안내, 링크)을 씌워 `dist/index.html`을 만들어요 |
| `demo/sample-db.js` | 시연용 가짜 저장소와 예시 기록. 진짜 claude.ai 앱 안에서는 켜지지 않아요 |
| `vercel.json` | Vercel 설정: 올릴 때 `node build.js`를 돌리고 `dist/`만 보여 줘요 |
| `.claude/preview-server.js`, `.claude/launch.json` | 컴퓨터에서 미리 보기: `node .claude/preview-server.js` → http://localhost:8124 |
| `CLAUDE.md` | Claude가 이 저장소에서 지킬 규칙 |
